= Saiba mais sobre o suporte do ONTAP à segurança FC-SP-3
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partir do ONTAP 9.20.1, o ONTAP oferece suporte à autenticação e à criptografia do Fibre Channel Security Protocol 3 (FC-SP-3) para adaptadores de barramento de host (HBAs) seguros da Broadcom em determinados sistemas ONTAP. O FC-SP-3 fornece criptografia em nível de hardware e autenticação de dispositivos para ajudar a proteger os dados em trânsito entre hosts FC e NVMe/FC e sistemas de storage ONTAP contra interceptação, adulteração e acesso não autorizado, mantendo o desempenho e alinhando-se aos padrões de segurança FC T11.

Os seguintes HBAs seguros da Broadcom suportam FC-SP-3:

* Cartões alvo: LPe38104
* Placas iniciadoras: LPe38102 (64G), LPe37102 (32G)


Use a link:https://hwu.netapp.com/["NetApp Hardware Universe"^] para verificar se o seu sistema ONTAP específico suporta os HBAs necessários.

Você também pode usar o  `fcp adapter show -fields transport-security-supported`comando para verificar se seu HBA suporta FC-SP-3. O campo *transport-security-supported* é *true* quando o FC-SP-3 é suportado.



[[enable-fc-sp-3-support]]
== Habilitar suporte a FC-SP-3

Se sua configuração for compatível com FC-SP-3, você poderá habilitá-lo ao link:../networking/create_a_lif.html["criar"] ou link:../networking/modify_a_lif.html["modificar"] uma interface de rede (LIF), definindo a `-fc-transport-security option` como *obrigatória* ou *preferencial*. Defina a opção como *obrigatória* para impedir que hosts que não suportam FC-SP-3 acessem o sistema de storage. Defina a opção como *preferencial* para que o ONTAP tente uma conexão FC-SP-3, permitindo o acesso do host caso a conexão FC-SP-3 não possa ser estabelecida.
