= Fluxo de trabalho de verificações pós-atualização do ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Depois de atualizar o ONTAP, há várias tarefas que você deve executar para verificar a prontidão do cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"]Verifique seu cluster.
[role="quick-margin-para"]
Após atualizar o ONTAP, você deve link:task_verify_cluster_after_upgrade.html["Verifique a versão do seu cluster, a integridade do cluster e a integridade do storage"]. Se você estiver usando uma configuração FC do MetroCluster, também precisa verificar se o cluster está habilitado para switchover automático não planejado.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"]Verifique se todas as LIFs estão nas home ports.
[role="quick-margin-para"]
Durante uma reinicialização, algumas LIFs podem ter sido migradas para suas portas de failover atribuídas. Após atualizar um cluster, você deve link:task_enabling_and_reverting_lifs_to_home_ports_post_upgrade.html["Habilite e reverta quaisquer LIFs que não estejam em suas portas de origem"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Três"]Verifique as considerações especiais específicas do seu cluster.
[role="quick-margin-para"]
Se existirem determinadas configurações no seu cluster, você poderá precisar de link:concept_special_configurations_post_checks.html["Execute etapas adicionais após a atualização"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatro"]Atualize o Pacote de Qualificação de Disco (DQP).
[role="quick-margin-para"]
O DQP não é atualizado como parte de uma atualização do ONTAP. Você deve link:concept_when_you_need_to_update_the_disk_qualification_package.html["atualizar o DQP"] após a atualização.
