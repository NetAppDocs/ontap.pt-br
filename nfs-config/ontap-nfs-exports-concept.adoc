= Saiba mais sobre as exportações NFS do ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O ONTAP controla o acesso de clientes NFS por meio de políticas de exportação atribuídas a volumes ou qtrees. Cada política contém regras que definem quais clientes podem acessar os dados e as permissões que recebem.



[[export-policies-and-rules]]
== Políticas e regras de exportação

Uma SVM pode conter várias políticas de exportação. Cada política pode conter zero ou mais regras de exportação que especificam correspondências de clientes e permissões de acesso. Uma política vazia nega todo o acesso. Você pode aplicar uma política de exportação a mais de um volume.



[[apply-export-policies-to-volumes-and-qtrees]]
== Aplicar políticas de exportação a volumes e qtrees

Atribua uma política de exportação a um volume ou qtree para controlar o acesso do cliente NFS a esse armazenamento. Uma política atribuída a um volume aplica-se aos dados do volume; você pode atribuir uma política diretamente a um qtree quando precisar controlar o acesso a esse qtree.



[[volume-junction-paths]]
== Caminhos de junção de volume

Os volumes são montados no namespace SVM em um caminho de junção. Os clientes NFS usam esse caminho para acessar os dados do volume. O caminho de junção pode ser diferente do nome do volume.
