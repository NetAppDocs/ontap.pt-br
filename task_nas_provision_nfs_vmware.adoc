= Provisione armazenamento NFS para datastores VMware com o ONTAP System Manager
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Antes de usar as ONTAP tools for VMware vSphere para provisionar volumes NFS em um sistema de storage baseado em ONTAP para hosts ESXi, habilite o NFS usando o System Manager para ONTAP 9.7 ou posterior.

Após criar um link:task_nas_enable_linux_nfs.html["VM de storage habilitada por NFS"] no System Manager, você provisiona volumes NFS e gerencia datastores usando o ONTAP tools for VMware vSphere.

Certifique-se de verificar a  https://imt.netapp.com/matrix/["Matriz de interoperabilidade do NetApp"^] para confirmar a compatibilidade entre sua versão atual do ONTAP e o ONTAP tools for VMware vSphere.

Para configurar o acesso NFS de hosts ESXi a datastores usando o System Manager Classic (para o ONTAP 9.7 e versões anteriores), consulte https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["Visão geral da configuração NFS para ESXi"^]

Para obter mais informações, consulte  https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["TR-4597: VMware vSphere for ONTAP"^] e o  https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["Ferramentas do ONTAP para documentação do VMware vSphere"^].
