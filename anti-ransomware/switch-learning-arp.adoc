= Mude para o modo ativo no ONTAP ARP após um período de aprendizagem
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para ambientes NAS, alterne manualmente ou automaticamente um volume com ARP habilitado do modo de aprendizado para o modo ativo. Você precisa alternar os modos se estiver usando ARP com o ONTAP 9.10.1 a 9.15.1 ou se o ARP estiver em execução em volumes FlexGroup no ONTAP 9.13.1 a 9.17.1.


NOTE: A proteção ARP/AI (ONTAP 9.16.1 e posterior) não requer um período de aprendizagem. A proteção ARP/AI é ativada imediatamente nos volumes FlexVol. Para volumes FlexGroup, o ARP/AI requer ONTAP 9.18.1. Não existe um procedimento equivalente de troca de modo para ARP/AI. Se você estiver executando ONTAP 9.16.1 ou posterior, consulte link:index.html["Saiba mais sobre proteção autônoma contra ransomware."].

Após o ARP concluir um período de aprendizado de no mínimo 30 dias (recomendado), você pode alternar manualmente para o modo ativo. A partir do ONTAP 9.13.1, o ARP determina automaticamente o intervalo ideal para o período de aprendizado e automatiza a transição, que pode ocorrer antes de 30 dias.


NOTE: Nos volumes existentes, os modos de aprendizagem e ativos aplicam-se apenas a dados recém-gravados, não a dados já existentes no volume. Os dados existentes não são digitalizados e analisados, porque as caraterísticas do tráfego de dados normal anterior são assumidas com base nos novos dados depois que o volume é ativado para ARP.



[[manually-switch-to-active-mode-after-a-learning-period]]
== Alterne manualmente para o modo ativo após um período de aprendizagem

Para o ONTAP 9.10.1 a 9.15.1 (e volumes FlexGroup no ONTAP 9.13.1 a 9.17.1), você pode fazer a transição manual do modo de aprendizado ARP para o modo ativo usando o System Manager ou a CLI do ONTAP após a conclusão do período de aprendizado.

.Passos
[role="tabbed-block"]
====
.System Manager
--
. Selecione *armazenamento > volumes* e, em seguida, selecione o volume que está pronto para o modo ativo.
. Na guia *Segurança* da visão geral *volumes*, selecione *mudar para o modo ativo* na caixa Anti-ransomware.
. Verifique o estado ARP do volume na caixa *Anti-ransomware*.


--
.CLI
--
. Altere o volume protegido para o modo ativo:
+
[source, cli]
----
security anti-ransomware volume enable -volume <vol_name> -vserver <svm_name>
----
+
Você também pode alternar para o modo ativo com o comando  `volume modify`:

+
[source, cli]
----
volume modify -volume <vol_name> -vserver <svm_name> -anti-ransomware-state enabled
----
. Verifique o estado ARP do volume:
+
[source, cli]
----
security anti-ransomware volume show
----


--
====


[[automatic-switching-from-learning-mode-to-active-mode]]
== Mudança automática do modo de aprendizagem para o modo ativo

A partir do ONTAP 9.13.1, o aprendizado adaptativo foi adicionado ao ARP Analytics, e a alternância do modo de aprendizado para o modo ativo é feita automaticamente. A decisão autônoma do ARP de alternar automaticamente do modo de aprendizado para o modo ativo é baseada nas configurações das seguintes opções:

[listing]
----
 -anti-ransomware-auto-switch-minimum-incoming-data-percent
 -anti-ransomware-auto-switch-duration-without-new-file-extension
 -anti-ransomware-auto-switch-minimum-learning-period
 -anti-ransomware-auto-switch-minimum-file-count
 -anti-ransomware-auto-switch-minimum-file-extension
----
Se a alternância automática estiver habilitada, o volume mudará para o modo ativo automaticamente após um máximo de 30 dias, mesmo que todas as condições não sejam atendidas. Esse limite de 30 dias é fixo e não pode ser alterado.

Você pode desativar a troca automática do modo de aprendizado para o modo ativo em todos os volumes de uma SVM, caso prefira controlar a transição manualmente:

[source, cli]
----
vserver modify <svm_name> -anti-ransomware-auto-switch-from-learning-to-enabled false
----
Para obter mais informações sobre opções de configuração ARP, incluindo valores padrão, consulte link:https://docs.netapp.com/us-en/ontap-cli/security-anti-ransomware-volume-auto-switch-to-enable-mode-show.html["Referência do comando ONTAP"^].
