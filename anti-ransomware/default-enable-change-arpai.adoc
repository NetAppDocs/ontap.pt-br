= Gerencie a capacitação automática de ARP/AI do ONTAP durante as atualizações
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:imagesdir: ../media/


[role="lead"]
Ao atualizar para o ONTAP 9.18.1 ou posterior, a Proteção Autônoma contra Ransomware com IA (ARP/AI) é ativada automaticamente por padrão em todos os novos volumes para os sistemas AFF série A, AFF série C, ASA e ASA r2 após um período de carência de 12 horas, desde que uma licença antiransomware esteja instalada. Use este procedimento para desativar a capacitação automática padrão durante ou após o período de carência, ou para alterar a configuração a qualquer momento após a atualização.


NOTE: Se você estiver executando o ONTAP 9.15.1 ou anterior, consulte link:index.html["Saiba mais sobre proteção autônoma contra ransomware."].


NOTE: Se você estiver executando o ONTAP 9.17.1 ou anterior, a capacitação padrão automática no nível do cluster não se aplica. Você pode configurar a capacitação padrão no nível da SVM usando link:enable-default-arpai.html["Ative o ARP/AI por padrão em novos volumes"].


NOTE: Os volumes existentes devem ser link:enable-arpai.html["ativado manualmente"] para ARP/AI.


NOTE: A partir do ONTAP 9.19.1, a capacitação padrão de ARP/AI se aplica a clusters que incluem SnapMirror síncrono e SnapMirror active sync em relacionamentos SAN. No ONTAP 9.18.1, a capacitação padrão foi suprimida para essas configurações. Para relacionamentos SnapMirror síncronos entre clusters, a capacitação padrão é ativada após a atualização dos clusters de origem e destino para o ONTAP 9.19.1.

.Sobre esta tarefa
A configuração escolhida pode ser alterada posteriormente. Após o período de carência, você sempre terá a flexibilidade de ativar ou desativar a capacitação padrão automática a qualquer momento:

[source, cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false|true
----
.Passos
Você pode usar o System Manager ou a CLI do ONTAP para gerenciar a capacitação automática padrão de ARP/AI.

[role="tabbed-block"]
====
.System Manager
--
. Selecione *Cluster > Settings*.
. Execute um dos seguintes procedimentos:
+
** Desativar durante o período de carência ativo:
+
... Na seção *Anti-ransomware*, você verá uma mensagem indicando as horas restantes antes que o ARP/AI seja ativado. Selecione *Don't enable*.
... Selecione *Desativar* na próxima caixa de diálogo para confirmar que a capacitação padrão de ARP/AI está desativada para novos volumes.


** Desativar após período de carência:
+
... Na seção *Anti-ransomware*, selecione image:icon_pencil.gif["Ícone de edição"].
... Selecione a caixa de seleção e clique em *Salvar* para desativar a capacitação automática padrão de ARP/AI para novos volumes.






--
.CLI
--
. Verifique o status de capacitação automática:
+
[source, cli]
----
security anti-ransomware auto-enable show
----
. Desative a capacitação automática padrão para novos volumes:
+
[source, cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false
----
