= Saiba mais sobre a eficiência de armazenamento do processador de offload dedicado ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A eficiência de storage com processador de descarregamento dedicado realiza o empacotamento sequencial de blocos físicos contíguos e usa um processador de descarregamento dedicado para a compressão de dados de 32k. Com a compressão de 32k, a economia de espaço é obtida no nível do agregado, diferentemente dos sistemas que usam compactação adaptável de 8k, em que a economia de espaço é obtida no nível do volume. Os sistemas que usam eficiência de storage com processador de descarregamento dedicado não usam eficiência de storage sensível à temperatura (TSSE), o que significa que a compressão não se baseia em dados quentes ou frios. Isso resulta em economia imediata de espaço sem qualquer impacto no desempenho.

O suporte a QuickAssist Technology (QAT) é necessário para a eficiência de storage do processador de descarregamento dedicado e é compatível com os sistemas a seguir. Ele é ativado por padrão nos sistemas AFF listados.


NOTE: Os sistemas AFF A20 não oferecem suporte à eficiência de storage do processador de descarregamento dedicado. Para os sistemas AFF A20, os dados migrados usando a tecnologia SnapMirror são convertidos automaticamente em compressão inline de 32k usando a CPU principal.

* Sistemas AFF A-Series: AFF A1K, AFF A90, AFF A70, AFF A50, AFF A30
* Sistemas AFF Série C: AFF C80, AFF C60, AFF C30
* Sistemas FAS: FAS90, FAS70, FAS50


Os sistemas ASA r2 e AFX também oferecem suporte a QAT e à capacitação padrão da eficiência de storage do processador de descarregamento dedicado.

* Os sistemas ASA r2 oferecem uma experiência ONTAP simplificada, específica para clientes apenas SAN. link:https://docs.netapp.com/us-en/asa-r2/get-started/learn-about.html["Saiba mais sobre os sistemas ASA r2"].
* Os sistemas AFX fornecem uma solução ONTAP específica para as necessidades exclusivas de clientes de NAS e S3 de alto desempenho link:https://docs.netapp.com/us-en/ontap-afx/get-started/ontap-afx-storage.html["Saiba mais sobre os sistemas AFX"].


Para os seguintes sistemas, a eficiência de storage é ativada automaticamente e não requer configuração. Isso se aplica a todos os volumes com thin provisioning recém-criados e aos dados existentes, incluindo volumes movidos de outros sistemas. A deduplicação é ativada independentemente da configuração de garantia de espaço. A compressão e a compactação exigem que a garantia de espaço seja definida como nenhuma. Os dados migrados usando a movimentação de volume ou a tecnologia SnapMirror são convertidos automaticamente para compressão inline de 32k.

* Sistemas AFF A-Series: AFF A1K, AFF A90, AFF A70, AFF A50, AFF A30
* Sistemas AFF Série C: AFF C80, AFF C60, AFF C30


Para os sistemas a seguir, a eficiência de storage é ativada por padrão apenas em volumes existentes com thin provisioning que já tinham a eficiência de storage ativada antes da atualização para o ONTAP 9.15.1 ou posterior. Você pode ativar a eficiência de storage em volumes recém-criados usando a interface de linha de comando do ONTAP ou a API REST do ONTAP. Os dados migrados usando a movimentação de volume ou a tecnologia SnapMirror são convertidos para compressão inline de 32k somente se a compressão estava ativada na plataforma original.

* FAS90
* FAS70
* FAS50


Para obter informações sobre como atualizar um controlador para um dos sistemas suportados, consulte o  https://docs.netapp.com/us-en/ontap-systems-upgrade/choose_controller_upgrade_procedure.html["Documentação de atualização de hardware do ONTAP"^].
