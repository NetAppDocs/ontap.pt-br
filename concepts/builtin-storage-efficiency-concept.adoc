= Saiba mais sobre a eficiência de armazenamento do processador de offload dedicado ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A eficiência de storage com processador dedicado de offload realiza o empacotamento sequencial de blocos físicos contíguos e utiliza um processador dedicado de offload para a compactação de dados de 32k. Com a compactação de 32k, a economia de espaço é obtida no nível do agregado, diferentemente dos sistemas que utilizam compactação adaptável de 8k, onde a economia de espaço é obtida no nível do volume. Os sistemas que utilizam eficiência de storage com processador dedicado de offload não utilizam eficiência de storage sensível à temperatura (TSSE), ou seja, a compactação não se baseia em dados quentes ou frios. Isso resulta em economia de espaço imediata sem qualquer impacto no desempenho.

A eficiência de storage com processador de offload dedicado é suportada nos seguintes sistemas. Ela está ativada por padrão nos sistemas AFF listados.


NOTE: A plataforma AFF A20 não suporta eficiência de storage dedicada com processador de offload. Para sistemas AFF A20, os dados migrados usando a tecnologia SnapMirror são convertidos automaticamente para compactação inline de 32k usando a CPU principal.

* Sistemas AFF A-Series: AFF A90, AFF A70, AFF A50, AFF A30
* AFF A1K
* Sistemas AFF Série C: AFF C80, AFF C60, AFF C30
* Sistemas FAS: FAS90, FAS70, FAS50


Para os seguintes sistemas, a eficiência de storage é ativada automaticamente e não requer configuração. Isso se aplica a todos os volumes com thin provisioning recém-criados e aos dados existentes, incluindo volumes movidos de outros sistemas. A deduplicação é ativada independentemente da configuração de garantia de espaço. A compressão e a compactação exigem que a garantia de espaço seja definida como nenhuma. Os dados migrados usando a movimentação de volume ou a tecnologia SnapMirror são convertidos automaticamente para compressão inline de 32k.

* Sistemas AFF A-Series: AFF A90, AFF A70, AFF A50, AFF A30
* AFF A1K
* Sistemas AFF Série C: AFF C80, AFF C60, AFF C30


Para os seguintes sistemas, a eficiência de storage é ativada por padrão apenas em volumes existentes com thin provisioning que já tinham a eficiência de storage ativada antes da atualização para o ONTAP 9.15.1 ou posterior. Você pode ativar a eficiência de storage em volumes recém-criados usando o ONTAP CLI ou o ONTAP API REST. Os dados migrados usando a movimentação de volume ou a tecnologia SnapMirror são convertidos para compactação inline de 32k somente se a compactação estava ativada na plataforma original.

* FAS90
* FAS70
* FAS50


Para obter informações sobre como atualizar um controlador para um dos sistemas suportados, consulte o  https://docs.netapp.com/us-en/ontap-systems-upgrade/choose_controller_upgrade_procedure.html["Documentação de atualização de hardware da ONTAP"^].
