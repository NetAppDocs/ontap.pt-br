= Modificar a capacidade do volume de destino em uma relação de DR de SVM do ONTAP
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
A partir do ONTAP 9.20.1, os administradores de armazenamento e os administradores de proteção de dados podem ajustar alguns atributos de capacidade de volume em um volume de destino de DR da SVM para manter os limites de dimensionamento automático do destino alinhados com o crescimento da origem, para aumentar a reserva de snapshots para a retenção do destino, e os administradores do provedor de serviços podem gerenciar com precisão os clientes de DR de alocação a vários clientes com base na capacidade do destino.



[[adjust-the-maximum-size-svm-dr-destination-volumes-can-grow-automatically]]
== Ajuste o tamanho máximo que os volumes de destino do SVM DR podem aumentar automaticamente

.Passos
. Para modificar o valor máximo de dimensionamento automático do volume, digite o seguinte comando:
+
`volume modify -vserver <dest svm name> -volume <vol name> -max-autosize <integer>`

+
Exemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -max-autosize 10TB
----




[[adjust-the-minimum-size-svm-dr-volumes-can-shrink-automatically]]
== Ajuste o tamanho mínimo que os volumes do SVM DR podem reduzir automaticamente

. Para modificar o valor mínimo de dimensionamento automático de um volume, digite o seguinte comando:
+
`volume modify -vserver <dest svm name> -volume vol1 -min-autosize <integer>`

+
Exemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -min-autosize 1TB
----




[[change-the-volumes-autosize-mode]]
== Altere o modo de dimensionamento automático do volume

. Para alterar o modo de dimensionamento automático, digite o seguinte comando:
+
`volume modify -vserver svmdr_dst -volume vol1 -autosize-mode`

+
Exemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -autosize-mode grow
----




[[adjust-the-amount-of-space-reserved-for-snapshots]]
== Ajuste a quantidade de espaço reservado para Snapshots

. Para alterar a porcentagem de espaço reservado para Snapshots, digite o seguinte comando:
+
`volume modify -vserver <dest svm name> -volume <vol name> -percent-snapshot-space <integer>`

+
Exemplo:

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -percent-snapshot-space 25
----
