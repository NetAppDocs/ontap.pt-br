= Habilitar ou desabilitar VMware vStorage sobre ONTAP NFS
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode habilitar ou desabilitar o suporte para VMware vStorage sobre NFS em máquinas virtuais de storage (SVMs) usando o `vserver nfs modify` comando. Essa configuração controla as operações do VMware VAAI sobre NFS, como descarregamento de cópia e reserva de espaço.

.Sobre esta tarefa
Por padrão, o suporte ao VMware vStorage sobre NFS está desativado.

A partir do ONTAP 9.20.1, a habilitação do VMware vStorage over ONTAP NFS também oferece suporte à exigência automática de espaço para datastores NFSv3 e NFSv4.1 com thin provisioning.

.Passos
. Verifique a configuração atual do VMware vStorage sobre NFS para a SVM:
+
`vserver nfs show -vserver vserver_name -fields vstorage`

. Execute uma das seguintes ações:
+
[cols="2*"]
|===
| Se você quiser... | Digite o seguinte comando... 


 a| 
Habilite o suporte ao VMware vStorage
 a| 
`vserver nfs modify -vserver vserver_name -vstorage enabled`



 a| 
Desative o suporte ao VMware vStorage
 a| 
`vserver nfs modify -vserver vserver_name -vstorage disabled`

|===
. Verifique se a configuração está atualizada:
+
`vserver nfs show -vserver vserver_name -fields vstorage`



.Depois de terminar
Você precisa instalar o NetApp NFS Plug-in for VMware VAAI antes de usar essa funcionalidade. A exigência de espaço automática requer a versão 3.0 ou posterior.

Para requisitos de host do VMware, plug-in e interoperabilidade, consulte a documentação do NetApp NFS Plug-in for VMware VAAI e a NetApp Ferramenta de Matriz de Interoperabilidade.
