= Versões e funcionalidade ONTAP SMB compatíveis
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O Server Message Block (SMB) é um protocolo de compartilhamento remoto de arquivos usado por clientes e servidores Microsoft Windows. O ONTAP suporta todas as versões do SMB. Você deve verificar se o servidor SMB do ONTAP oferece suporte aos clientes e à funcionalidade necessária em seu ambiente.

As informações mais recentes sobre quais clientes SMB e controladores de domínio o ONTAP suporta estão disponíveis na _ferramenta Matriz de interoperabilidade_.

O SMB 2.0 e as versões posteriores são habilitados por padrão para os servidores SMB do ONTAP e podem ser habilitados ou desabilitados conforme necessário. Da mesma forma, o SMB 1.0 pode ser habilitado ou desabilitado conforme necessário.

A partir do ONTAP 9.20.1, o ONTAP oferece suporte a consultas de nomes normalizados SMB para arquivos e diretórios abertos. Os clientes Windows podem recuperar nomes canônicos de arquivos e diretórios em uma única solicitação.

[NOTE]
====
As configurações padrão para conexões SMB 1.0 e 2.0 com controladores de domínio também dependem da versão do ONTAP. Saiba mais sobre o `vserver cifs security modify` comando na link:https://docs.netapp.com/us-en/ontap-cli/vserver-cifs-security-modify.html["Referência do comando ONTAP"^]. Para ambientes com servidores CIFS existentes que executam SMB 1.0, a NetApp recomenda migrar para uma versão posterior do SMB o mais rápido possível para se preparar para aprimoramentos de segurança e conformidade. Entre em contato com seu representante da NetApp para obter detalhes.
