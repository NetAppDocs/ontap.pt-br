= Redefinir e redescobrir domínios SMB confiáveis do ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode forçar a redescoberta de todos os domínios confiáveis. Isso pode ser útil quando os servidores de domínio confiáveis não estão respondendo adequadamente ou as relações de confiança foram alteradas. Somente domínios com confiança bidirecional com o domínio home, que é o domínio que contém a conta de computador do servidor CIFS, são descobertos.

A partir do ONTAP 9.13.1, quando o ONTAP redescobre domínios confiáveis, ele também realiza a descoberta de sites para esses domínios confiáveis. O ONTAP usa as informações de site descobertas para pesquisas de controlador de domínio de domínios confiáveis. Isso ajuda a garantir que as pesquisas DNS SRV usem as informações de site corretas para controladores de domínio de domínios confiáveis. Se a descoberta de sites para um domínio confiável falhar, o ONTAP usa o site padrão do servidor SMB.

.Passo
. Redefina e redescubra domínios confiáveis usando o `vserver cifs domain trusts rediscover` comando.
+
`vserver cifs domain trusts rediscover -vserver vs1`
