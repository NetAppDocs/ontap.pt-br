= Operações e filtros de arquivo FPolicy suportados para NFSv4 no ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Ao configurar seu evento FPolicy, você precisa estar ciente de que apenas certas combinações de operações de arquivo e filtros são suportadas para monitorar operações de acesso a arquivos NFSv4.

A partir do ONTAP 9.15,1, o FPolicy suporta o protocolo NFSv4,1.

A partir do ONTAP 9.19.1, os administradores podem controlar a disponibilidade do NFSv4.2 no nível da SVM, habilitando ou desabilitando o protocolo para VMs de armazenamento individuais usando o System Manager, a CLI ou a API REST.

A partir do ONTAP 9.20.1, o FPolicy oferece suporte ao monitoramento de eventos de acesso a arquivos NFSv4.2, incluindo novas operações de arquivo para gravações de atributos estendidos (xattr) e filtros de rótulo de segurança para a atividade de NFS rotulado. Saiba mais sobre link:../nfs-admin/enable-disable-nfs-task.html["habilitar ou desabilitar o NFS para SVMs do ONTAP"].


NOTE: Os filtros de rótulo de segurança (`setattr_with_security_label_change` e `getattr_with_security_label_read`) exigem que os rótulos de segurança do NFSv4.2 (Labeled NFS) sejam habilitados na SVM. Saiba mais sobre link:../nfs-admin/enable-nfsv42-security-labels-task.html["habilitando rótulos de segurança do NFSv4.2"]. `getxattr` e `listxattrs` são operações somente leitura e não são monitoradas pelo FPolicy.
