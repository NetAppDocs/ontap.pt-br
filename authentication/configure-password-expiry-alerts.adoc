= Configure os alertas de expiração da senha do usuário do ONTAP no System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partir do ONTAP 9.20.1, se a função associada a uma conta de usuário estiver configurada para alertas de expiração de senha, o usuário recebe um alerta de banner na parte superior da página do System Manager imediatamente após fazer login, a partir de 14 dias antes da expiração da senha. O alerta é atualizado a cada login do usuário para mostrar o número de dias restantes até a expiração da senha. Você pode configurar alertas de expiração ao adicionar ou editar uma função de administrador.

.Passos
. Selecione *Cluster > Settings*.
. Selecione image:icon_arrow.gif["ícone de seta"] ao lado de *Usuários e funções*.
. Configure alertas de expiração de senha ao adicionar ou editar uma função de usuário.
+
** Para configurar ao adicionar uma função de usuário, em *Funções*, selecione image:icon_add.gif["adicionar ícone"]. Insira um nome para a função e, em seguida, selecione o período de expiração da senha e um alerta de expiração da senha.
** Para configurar isso ao editar uma função de usuário, em *Funções*, selecione a função de usuário. Selecione *Editar* e, em seguida, selecione o período de expiração da senha.
** Selecione *Adicionar*.




.Resultado
O usuário recebe um alerta em forma de banner no topo da página do System Manager imediatamente após fazer login, a partir do número de dias selecionado antes do vencimento da senha. O alerta é atualizado a cada login do usuário para mostrar o número de dias restantes até o vencimento da senha.
