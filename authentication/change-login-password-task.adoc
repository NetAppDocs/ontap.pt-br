= Altere uma senha de administrador do ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você deve alterar sua senha inicial de administrador do ONTAP imediatamente após fazer login pela primeira vez e periodicamente depois disso, para ajudar a manter seu cluster seguro.

A partir do ONTAP 9.20.1, se a sua conta de usuário estiver configurada para alertas de expiração de senha, o System Manager exibe um alerta em banner a partir de 14 dias antes de a sua senha expirar. O alerta é atualizado sempre que você faz login para mostrar o número de dias restantes.

.Sobre esta tarefa
A nova palavra-passe deve respeitar as seguintes regras:

* Não pode conter o nome de utilizador
* Deve ter pelo menos oito carateres
* Deve conter pelo menos uma letra e um número
* Não pode ser o mesmo que as últimas seis senhas



NOTE: Você pode usar o `security login role config modify` comando para modificar as regras de senha para contas associadas a uma determinada função.

.Antes de começar
* Você deve ser um administrador de cluster ou SVM para alterar sua própria senha.
* Você deve ser um administrador de cluster para alterar a senha de outro administrador.


.Passos
Use o System Manager ou a interface de linha de comando do ONTAP (CLI) para alterar sua senha.

[role="tabbed-block"]
====
.System Manager
--
. No System Manager, selecione *Cluster > Settings*.
. Em *Usuários e Funções*, selecione *Usuários*.
. Selecione image:icon_kabob.gif["Menu"] ao lado da conta de usuário para a qual você precisa alterar a senha e, em seguida, selecione *Alterar senha*.
. Digite a nova senha.
. Digite novamente a nova senha para confirmá-la e, em seguida, selecione *Salvar*.


--
.CLI
--
Se você for um administrador do SVM, poderá usar o `security login password` comando para alterar sua própria senha. Se você for um administrador do cluster, poderá usar o `security login password` comando para alterar a senha de qualquer administrador.

. Alterar uma palavra-passe de administrador: `security login password -vserver _svm_name_ -username _user_name_`
+
O comando a seguir altera a senha do administrador `admin1` da SVM `vs1.example.com`. Você deve inserir a senha atual e, em seguida, inserir e confirmar a nova senha.

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----
